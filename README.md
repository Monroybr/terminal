🚍 Terminal - Sistema Web de Transporte Terrestre
Sistema web desarrollado para la gestión y compra de tiquetes de transporte terrestre, permitiendo a los usuarios consultar rutas, horarios, empresas disponibles, cotizar viajes y realizar reservas de manera rápida, sencilla y segura. El proyecto fue desarrollado utilizando tecnologías web como HTML5, CSS3, JavaScript, PHP y MySQL, integrando funcionalidades dinámicas tanto en el frontend como en el backend. Además, el sistema cuenta con optimización SEO, diseño responsive y validaciones en formularios para mejorar la experiencia del usuario.
📌 Características principales


Consulta de rutas y horarios de viaje.


Cotización de viajes según origen, destino y tipo de servicio.


Compra y reserva de tiquetes.


Gestión de información de pasajeros.


Integración con base de datos MySQL.


Generación de pedidos mediante PHP.


Validaciones de formularios.


Diseño responsive adaptable a dispositivos móviles.


Optimización SEO On-Page y SEO Técnico.


Implementación de Sitemap.xml y Robots.txt.


Integración con envío de correos electrónicos.


Optimización de imágenes y rendimiento web.

⚙️ Instalación del proyecto


Clonar el repositorio desde GitHub:


git clone https://github.com/Monroybr/terminal.git


Mover la carpeta del proyecto dentro de:


C:\xampp\htdocs\terminal


Abrir XAMPP e iniciar:




Apache


MySQL




Ingresar a phpMyAdmin:


http://localhost/phpmyadmin


Crear la base de datos llamada:


terminal


Importar el archivo SQL del proyecto.


Configurar la conexión en:


api/config.php
Con los siguientes datos:


host: 127.0.0.1


port: 3306


database: terminal


user: root


password: vacío


🚀 Ejecución del proyecto
Abrir el navegador e ingresar:
http://localhost/terminal
